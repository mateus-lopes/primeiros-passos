# Módulo 1 · Pensando como programadora 🍳

Surpresa: neste módulo **não tem código nenhum**!

Antes de aprender a escrever na língua do computador, você vai aprender a **pensar** como ele. E vai descobrir que já faz isso há muito tempo, toda vez que segue uma receita, monta um treino ou faz as unhas.

Neste módulo, você vai aprender as três ideias que existem em **todo** programa do mundo:

- 📋 **Sequência:** fazer as coisas numa ordem
- 🔀 **Decisão:** escolher o que fazer dependendo da situação
- 🔁 **Repetição:** fazer a mesma coisa várias vezes

!!! tip "Pode usar papel"
    Se preferir pensar no papel antes de digitar, fique à vontade. Muita gente experiente faz exatamente isso. Só lembre de passar a limpo no arquivo do desafio para entregar.
