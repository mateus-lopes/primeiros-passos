# Módulo 0 · Preparando o cantinho 🧰

Antes de começar a programar, a gente precisa arrumar o espaço de trabalho, igual a separar os ingredientes e os utensílios antes de fazer um doce.

Neste módulo, você vai:

- Instalar os programas que vai usar na trilha toda
- Criar o lugar onde vai guardar e entregar os seus desafios
- Entender como estudar por aqui e como procurar respostas sozinha

| Lição | Tempo |
|---|---|
| [0.1 · Sessão 0: arrumando o computador](aula01-sessao-0.md) | ~2h (dividida em 2 dias) |
| [0.2 · Como usar esta trilha](aula02-como-usar-a-trilha.md) | ~1h |

!!! note "Esta parte é feita com companhia"
    A **Sessão 0** é a única lição que você faz junto com quem está te acompanhando. Instalar programas pode ter umas surpresas chatas, e ninguém precisa passar por isso sozinha. Depois dela, você já consegue seguir a trilha por conta própria.
