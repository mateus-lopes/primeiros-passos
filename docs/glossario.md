# 📖 Glossário

Toda palavra técnica que aparece na trilha está aqui, explicada do jeito mais simples possível. Esqueceu o que alguma coisa significa? Volte aqui sem culpa: até programador experiente vive procurando o significado das coisas.

As palavras estão em ordem alfabética, e cada uma diz em qual lição aparece pela primeira vez.

---

**Algoritmo** · *lição 1.1*
:   Uma sequência de passos, em ordem, para chegar a um resultado. Uma receita é um algoritmo!

**Bug** · *lição 1.2*
:   Um erro num programa. O nome vem de uma mariposa de verdade que foi achada dentro de um computador em 1947. 🦋

**Commit** · *lição 0.1*
:   Um "pacote" com as mudanças que você fez, com uma descrição. É como finalizar um pedido numa loja online. Comando: `git commit -m "descrição"`.

**Condição** · *lição 1.3*
:   Uma pergunta que só pode ser respondida com **sim** ou **não**. Exemplo: "a bola caiu dentro da quadra?". É ela que decide o que o **SE** vai fazer.

**Dados** · *lição 1.1*
:   As informações que um programa usa: um nome, um preço, um placar… São os "ingredientes" do programa.

**Git** · *lição 0.1*
:   Um programa que guarda o histórico de tudo o que você muda nos seus arquivos e ajuda a entregar seus desafios.

**GitHub** · *lição 0.1*
:   Um site onde você guarda seus projetos na internet. É lá que fica o seu repositório de desafios.

**Instrução** · *lição 1.1*
:   Uma ordem que o computador deve seguir. Um programa é uma lista de instruções.

**MDN** · *lição 0.2*
:   O site de referência da programação para a web: [developer.mozilla.org/pt-BR](https://developer.mozilla.org/pt-BR/). É onde você procura respostas.

**Navegador** · *lição 0.2*
:   O programa que você usa para abrir sites, como o Chrome, o Edge ou o Safari.

**Programar** · *lição 1.1*
:   Escrever as instruções que o computador vai seguir.

**Push** · *lição 0.1*
:   Enviar os seus commits para o GitHub. É o "enviar o pedido". Comando: `git push`.

**Recuo (ou indentação)** · *lição 1.3*
:   O espacinho no começo de uma linha. Mostra o que pertence a quê, por exemplo, quais passos fazem parte de um **REPITA**.

**Repetição** · *lição 1.3*
:   Fazer a mesma coisa várias vezes, um número de vezes (**REPITA 3 VEZES**) ou até algo acontecer (**REPITA ATÉ**).

**Repositório** · *lição 0.1*
:   Uma pasta de projeto que o Git acompanha. O seu se chama `desafios`.

**Sequência** · *lição 1.1*
:   Fazer as coisas uma depois da outra, na ordem.

**Terminal** · *lição 0.1*
:   Um jeito de conversar com o computador **escrevendo comandos**, em vez de clicar. No VS Code, ele fica na parte de baixo da tela.

**VS Code** · *lição 0.1*
:   O programa onde você escreve código. Um bloco de notas turbinado para programação.
